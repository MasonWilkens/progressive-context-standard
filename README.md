# Progressive Context Standard (PCS)

**Working draft:** 0.2.0-draft  
**Positioning:** A portable standard for clear, discoverable, and maintainable context.

PCS defines how information should be written and connected so people and automated systems can load relevant detail when needed. It complements existing progressive-disclosure systems rather than replacing their file formats or tools.

## Boundaries

PCS does not require a repository, a specific agent, English, Markdown, a vector database, or an automated maintainer. It does not authorize actions or replace access controls.

The specification defines separate claims for documentation sets, context consumers, and maintenance tools or processes. Static conformance does not demonstrate better task performance.

This package contains a draft specification and supporting material, not an implemented validator, a certification, or a published service. Illustrative examples are not real policy approvals or evaluated project claims.
