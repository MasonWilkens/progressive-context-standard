# Report format

**Purpose:** Identify presentation fields for the imaginary report workflow.  
**Read when:** Preparing the public copy of an approved report.  
**Scope:** Example public reports only.  
**Role:** Illustrative reference, not publication approval.

Include the report title, version identifier, intended audience, and source references needed to interpret the report.

Keep qualifications with the conclusions they qualify. Label illustrative values and assumptions. Preserve exact cited identifiers.

Formatting does not establish factual accuracy or publication permission. Read [Publication policy](publication-policy.md) before publishing externally.
