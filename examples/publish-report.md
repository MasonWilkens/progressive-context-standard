# Publish a report

**Purpose:** Prepare an approved report for public release.  
**Read when:** Publishing or replacing a public report.  
**Scope:** Imaginary project's public reports. Internal drafts are excluded.  
**Status:** Illustrative procedure; do not treat it as an authorized workflow.

## Before publication

Read [Publication policy](publication-policy.md) before creating a public copy. Confirm that the designated approver has approved the exact report version.

## Procedure

1. Identify the approved version and intended audience.
2. Apply [Report format](report-format.md) to that version.
3. Check references and required identifying fields.
4. Use the project's authorized publication process.
5. Record the public location and approved version.

## Completion condition

The public copy matches the approved report version and has a recorded location.

## Exception

Do not publish when approval is absent or unclear. Use the policy's escalation route. In this illustrative collection, the route is a named role rather than a real contact.
