# Example: publication knowledge

**Purpose:** Demonstrate a small PCS-style collection for an imaginary publication workflow.  
**Scope:** Public reports; not internal drafts.  
**Status:** Informative example, not a policy in force or a conformance claim.

| Unit | Select when |
|---|---|
| [Publish a report](publish-report.md) | Preparing a new public report or replacing a public version. |
| [Publication policy](publication-policy.md) | Checking whether a particular report version is authorized for public release. Required before publishing. |
| [Report format](report-format.md) | Preparing the layout and identifying fields for the public copy. |

If these units do not answer a question, contact the project's designated publication owner. That role is hypothetical in this example. No real escalation contact or publication endpoint is supplied.

The policy governs authorization in the example. The format reference governs presentation, not approval. None of these files grants real publication authority.
